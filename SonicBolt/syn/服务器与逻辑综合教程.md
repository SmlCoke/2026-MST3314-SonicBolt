## 4 服务器示例文件说明

### 库文件说明
`SMIC18` 为中芯国际 180nm 工艺库文件，逻辑综合所用到的库文件包含在 `SMIC18/lib` 和 `SMIC18/mem` 两个子文件夹中，前者为标准单元和 IO 库库文件，后者为 SRAM 库文件。

### 逻辑综合示例文件说明
`IDCT` 包含一个基于离散 DCT 变换设计的逻辑综合示例，其中包含 `IDCT/Syn/work`、`IDCT/Syn/rtl`、`IDCT/Syn/scripts`、`IDCT/Syn/report`、`IDCT/Syn/output` 五个子文件夹，分别为逻辑综合工具运行目录、rtl 代码目录、逻辑综合脚本目录、逻辑综合报告目录和逻辑综合结果目录。

### 设计模板文件说明
`CNN` 为本课程提供的设计模板的逻辑综合目录，其文件结构与 `IDCT` 类似。

## 5 服务器后台运行说明

考虑到服务器连接的不稳定性，我们推荐使用 screen 方式在后台运行，需要用到的命令如下：
*   `screen -S name`：创建名为 name 的 screen 环境
*   `screen -r name`：挂起后重新进入名为 name 的 screen 环境
*   `screen -ls`：查看当前 screen 列表
*   `ctrl+a+d`：挂起当前 screen
*   `ctrl+a+k`：杀掉当前 screen

按照如上命令即可创建 screen，运行相应操作，使用 `ctrl+a+d` 即可挂起 screen 在后台运行，通过 `screen -r name` 定期查看运行效果。

#### 库文件导入脚本对比

| Design Compiler | ZenSyn | 详细说明 |
| :--- | :--- | :--- |
| `set search_path "$search_path ../rtl/idct ../scripts ../../../SMIC18/db ../../../SMIC18/sdb ../work"` | `set search_path "$search_path ../rtl/idct ../scripts ../../../SMIC18/lib ../../../SMIC18/mem ../work"` | 均支持设置搜索路径 |
| `set target_library "slow.db S018V3EBCDSP_X16Y4D16_PR_tt_1.8_25.db"` | `set target_lib "slow.lib S018V3EBCDSP_X16Y4D16_PR.lib SP018W_V1p8_max.lib"` | 设置 target library 命令类似，但 ZenSyn 仅支持 .lib 文件格式，不支持 .db 文件格式 |
| `set symbol_library "smic18.sdb SP018W_V1p5.sdb"` | 无 | ZenSyn 无需设置 symbol library，直接生成实际工艺库下的网表 |
| `set link_library "* $target_library $symbol_library SP018W_V1p5_max.db S018V3EBCDSP_X16Y4D16_PR_tt_1.8_25.db"` | `set link_priority "* slow S018V3EBCDSP_X16Y4D16_PR_tt_1.8_25 SP018W_V1p8_max"` | 设置 link library 命令类似，由 `set link_library` 迁移为 `set link_priority` |
