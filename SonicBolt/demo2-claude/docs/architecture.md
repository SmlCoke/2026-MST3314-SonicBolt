# Conv1 硬件架构详解

---

## 1. 算法规格

| 参数 | 值 |
|------|-----|
| 输入尺寸 | (1, 30, 10) — 1 通道, 高 30, 宽 10 |
| 卷积核 | (32, 1, 11, 7) — 32 个输出通道, 高 11, 宽 7 |
| 偏置 | 32 个 INT32 值 |
| 步长 | stride = 1, padding = 0 |
| 输出尺寸 | (32, 20, 4) — 32 通道, 高 20, 宽 4 |
| 量化 | INT8 输入/输出, INT32 累加, M0=111, n=14 |

**输出尺寸推导**：
```
H_out = (H_in - K_h) / stride + 1 = (30 - 11) / 1 + 1 = 20
W_out = (W_in - K_w) / stride + 1 = (10 - 7) / 1 + 1 = 4
```

### 2.2 关键设计决策

| 设计点 | 选择 | 理由 |
|--------|------|------|
| 通道并行度 | 32 路全并行 | 最大吞吐量，每周期产出 32 个输出 |
| MAC 并行度 | 每 MAC 77 路全并行 | 消除 kernel 内串行延迟 |
| 行缓冲 | 循环指针 | 比移位省功耗/面积 |
| 流水级数 | MAC(组合)+Requant(组合)+1级寄存器 | 简单，关键路径可接受 |
| SRAM 接口 | 每周期 1 行 (80-bit) | 匹配输入带宽需求 |

## 3. 模块详解

### 3.1 Conv1_LineBuffer — 循环行缓冲

```
物理存储:  slot[0]  slot[1]  slot[2]  ...  slot[10]
                     ↑
                   wr_ptr (写指针)

逻辑映射:  line[0] = slot[(wr_ptr+0) % 11]  ← 最旧行
           line[1] = slot[(wr_ptr+1) % 11]
           ...
           line[10]= slot[(wr_ptr+10)% 11]  ← 最新行
```

**详细时序（FILL_LB 阶段）**：
```
Cycle  | wr_ptr | 操作                    | 缓冲内容
-------|--------|------------------------|---------------------------
  0    |   0    | slot[0] ← row 0       | [row0, -, -, ..., -]
  1    |   1    | slot[1] ← row 1       | [row0, row1, -, ..., -]
  ...  |  ...   | ...                    | ...
  10   |  10    | slot[10] ← row 10     | [row0, row1, ..., row10]
→ wr_ptr 回绕到 0
```

**详细时序（CALC_RUN 阶段，row 0→1 过渡）**：
```
Cycle  | row | col | wr_ptr | 操作
-------|-----|-----|--------|----------------------------------------
  11   |  0  |  0  |   0    | 计算 output(0,0), 不加载
  12   |  0  |  1  |   0    | 计算 output(0,1), 不加载
  13   |  0  |  2  |   0    | 计算 output(0,2), 不加载
  14   |  0  |  3  |   0    | 计算 output(0,3), 加载 row 11 到 slot[0]
                              wr_ptr → 1
  15   |  1  |  0  |   1    | 计算 output(1,0)
                              line[0]=slot[1]=row1 ✓
                              ...
                              line[10]=slot[0]=row11 ✓
```

### 3.2 窗口提取 (Window Extraction)

输入特征图每行 10 个像素（w=0~9），卷积核宽度 7。

```
           w=0  w=1  w=2  w=3  w=4  w=5  w=6  w=7  w=8  w=9
           ┌────┬────┬────┬────┬────┬────┬────┬────┬────┬────┐
line[0]   │ P0 │ P1 │ P2 │ P3 │ P4 │ P5 │ P6 │ P7 │ P8 │ P9 │
           ├────┼────┼────┼────┼────┼────┼────┼────┼────┼────┤
line[1]   │    │    │    │    │    │    │    │    │    │    │
           ├────┼────┼────┼────┼────┼────┼────┼────┼────┼────┤
  ...      │    │    │    │    │    │    │    │    │    │    │
           ├────┼────┼────┼────┼────┼────┼────┼────┼────┼────┤
line[10]  │    │    │    │    │    │    │    │    │    │    │
           └────┴────┴────┴────┴────┴────┴────┴────┴────┴────┘

col_cnt=0:  ╔════════════════════════════╗
            ║ w0  w1  w2  w3  w4  w5  w6 ║
            ╚════════════════════════════╝

col_cnt=1:       ╔════════════════════════════╗
                 ║ w1  w2  w3  w4  w5  w6  w7 ║
                 ╚════════════════════════════╝

col_cnt=3:                    ╔════════════════════════════╗
                              ║ w3  w4  w5  w6  w7  w8  w9 ║
                              ╚════════════════════════════╝
```

窗口数据 `window_flat` 的排列：按行优先，从 line[0] 到 line[10]，每行取 7 个连续像素。

### 3.3 Conv1_MACUnit — 乘累加单元

```
窗口数据: w[0], w[1], ..., w[76]    (77 个 INT8)
权重:     k[0], k[1], ..., k[76]    (77 个 INT8)
偏置:     bias                       (1 个 INT32)

                    ┌────┐
         w[0] ────►│ ×  │────► p[0]  (INT16)
         k[0] ────►│    │             │
                    └────┘             │
         w[1] ────►│ ×  │────► p[1]   ├──► Σ + bias ──► result (INT32)
         k[1] ────►│    │             │
                    └────┘             │
           ...       ...      ...     │
         w[76]────►│ ×  │────► p[76]  │
         k[76]────►│    │             │
                    └────┘
```

**硬件资源**：
- 77 个 8×8 有符号乘法器
- 约 7 级加法树（ceil(log2(77)) = 7）
- 1 个 32-bit 加法器（加偏置）
- 每个 MAC 单元共约 77 个乘法器 + 76 个加法器

**32 个 MAC 单元总计**：
- 乘法器: 32 × 77 = **2464 个**
- 这些 MAC 共享同一组输入数据，但各自使用不同的权重

### 3.4 Conv1_RequantUnit — 重量化单元

```
INT32 累加结果
      │
      ▼
  ┌────────┐
  │ × M0   │   M0 = 111
  │(111)   │
  └───┬────┘
      │  INT40
      ▼
  ┌────────┐
  │ >>> 14 │   算术右移 14 位
  └───┬────┘
      │  INT40 (有效值 ≤ 26 bits)
      ▼
  ┌────────┐
  │ clamp  │   < 0 → 0 (ReLU)
  │[0,127] │   > 127 → 127 (饱和)
  └───┬────┘
      │  INT8
      ▼
   输出
```

## 4. FSM 状态机

```
         start
  ┌────── │ ──────┐
  │       ▼       │
  │    ┌──────┐   │
  └────│ IDLE │   │
       └──┬───┘   │
          │ start  │
          ▼        │
  ┌─────────────┐  │
  │ LOAD_WEIGHT │  │ 2464 周期
  └──────┬──────┘  │
         ▼         │
  ┌─────────────┐  │
  │  LOAD_BIAS  │  │ 32 周期
  └──────┬──────┘  │
         ▼         │
  ┌─────────────┐  │
  │  FILL_LB    │  │ 11 周期
  └──────┬──────┘  │
         ▼         │
  ┌─────────────┐  │
  │  CALC_RUN   │  │ 80 周期
  └──────┬──────┘  │
         ▼         │
  ┌─────────────┐  │
  │    DONE     │──┘ 1 周期
  └─────────────┘
```

### 推理吞吐量分析

单次推理（不含权重加载）：
- FILL_LB: 11 周期
- CALC_RUN: 80 周期
- 总计: **91 周期**

吞吐量（连续推理时，权重只加载一次）：
```
@ 100 MHz: 1 / (91 × 10ns) ≈ 1.10M FPS
@ 120 MHz: 1 / (91 × 8.33ns) ≈ 1.32M FPS
@ 150 MHz: 1 / (91 × 6.67ns) ≈ 1.65M FPS
```

均满足 1000K FPS 的目标。

## 5. 存储资源分析

| 存储项 | 大小 | 实现方式 |
|--------|------|----------|
| 行缓冲 | 11 × 80 = 880 bit | 寄存器 |
| 权重存储 | 2464 × 8 = 19712 bit | 寄存器阵列 |
| 偏置存储 | 32 × 32 = 1024 bit | 寄存器阵列 |
| **总计** | **21616 bit ≈ 2.64 KB** | |

**注意**：当前权重使用寄存器阵列实现，面积较大。后续优化可改为 SRAM 宏单元存储，显著降低面积。

## 6. 关键路径分析

```
组合逻辑关键路径:

窗口提取(MUX) → 乘法器(8×8) → 加法树(7级) → 偏置加法 → 重量化乘法(32×8) → 右移 → clamp
    ~2ns           ~4ns         ~7ns          ~1ns         ~5ns            ~1ns   ~1ns
                                                                        总计 ≈ 21ns

在 0.18μm 工艺下:
  - 100 MHz (10ns): 需要至少 2 级流水
  - 当前实现: MAC+Requant 组合 + 1 级输出寄存器
  - 如果时序不满足，可在 MAC 和 Requant 之间插入流水寄存器
```

## 7. 与 MiniCNN 参考设计的对比

| 方面 | MiniCNN | SonicBolt Conv1 |
|------|---------|-----------------|
| 通道并行度 | 每周期 1 个 filter | 32 个 filter 全并行 |
| 空间并行度 | 4 个位置并行 | 1 个位置/周期 |
| 推理周期 | 32 × 9 = 288 周期 | 80 周期 |
| 权重存储 | SRAM 宏单元 (8 bank) | 寄存器阵列 |
| 行缓冲 | DataSelector (MUX) | 循环行缓冲器 |
| 加法树 | 分级流水 (MultAdd→Add2nd→Add3rd) | 单级组合逻辑 |
| 重量化 | 2 级流水 (乘→移位) | 组合逻辑 |
