# Verilog 语法笔记

## I. SystemVerilog 中的 `+:` 和 `-:` 语法

### 1.1 问题

```verilog
reg [7:0] B;   // 低位为低索引
A[0 +: 8] = B;
```
**A 这一段的高位对应 B 的低位还是高位？**

### 1.2 `+:` 语法含义

```verilog
A[base +: width]
```

表示：**从 base 开始，向高位方向取 width 位**

等价于：

```verilog
A[base + width - 1 : base]
```

因此：

```verilog
A[0 +: 8] ≡ A[7:0]
```



### 1.3 赋值时的位对应关系

```verilog
A[7:0] = B;
```

位一一对应：

```
A[7] = B[7]
A[6] = B[6]
...
A[0] = B[0]
```

✔ 不会发生位反转
✔ 高位对高位，低位对低位


### 1.4 `-:` 情况补充

```verilog
A[7 -: 8]
```

等价于：

```verilog
A[7:0]
```

仍然：

```
A[7] = B[7]
A[0] = B[0]
```

区别仅在“选择方向”，不会改变位序。


## II. 写指针回绕的高效实现
```verilog
// ── 步骤 2：写指针循环递增（模 KH）──────────────────────────────
//
//   if (wr_ptr == KH-1): wr_ptr ← 0    （回绕到开头）
//   else:                wr_ptr ← wr_ptr + 1
//
//   【为什么用 if-else 而非 % 运算符？】
//   % 在 Verilog 综合中生成除法器，面积大、时序差。
//   简单的比较+条件赋值综合为一个比较器 + 2:1 MUX，效率高。
if (wr_ptr == KH - 1)
    wr_ptr <= {PTR_BITS{1'b0}};     // 回绕到 0
else
    wr_ptr <= wr_ptr + 1'b1;        // 正常递增
```

写指针回绕的逻辑计算公式是：$\text{wr_ptr} = (\text{wr_ptr} + 1) \bmod KH$
但是在 Verilog 中直接使用 `% KH` 会导致综合工具生成一个除法器，面积大、时序差。使用 if-else 结构进行比较和条件赋值，可以综合为一个比较器和一个 2:1 MUX，效率更高。
